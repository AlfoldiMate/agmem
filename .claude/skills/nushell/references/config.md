# Configuration

Nushell 0.114.1. `config nu --doc | nu-highlight | less -R` is the authoritative
per-key reference generated by the running binary — prefer it over any snippet.

## Files and load order

```
1. env.nu                  legacy; runs first
2. config.nu               main config
3. vendor-autoload-dirs/*.nu   third-party, alphabetical
4. user-autoload-dirs/*.nu     yours, alphabetical
5. login.nu                login shells only
```

Defaults live in `$nu.default-config-dir`:

| OS | Path |
|---|---|
| macOS | `~/Library/Application Support/nushell` |
| Linux | `~/.config/nushell` |
| Windows | `%APPDATA%\nushell` |

Overridable only by `XDG_CONFIG_HOME` (Nushell appends `/nushell`) or the
`--config` / `--env-config` flags. **There is no `NU_CONFIG_DIR`.**

Since 0.101 the modern advice is: put everything in `config.nu` or the autoload
dirs, and leave `env.nu` empty.

## What loads when

| Invocation | `env.nu` | `config.nu` | `login.nu` | autoload | hooks |
|---|---|---|---|---|---|
| `nu` | ✅ | ✅ | ❌ | ✅ | ✅ |
| `nu -l` | ✅ | ✅ | ✅ | ✅ | ✅ |
| `nu -c "…"` | ❌ | ❌ | ❌ | ❌ | ❌ |
| `nu script.nu` | ❌ | ❌ | ❌ | ❌ | ❌ |
| `nu -n` | ❌ | ❌ | ❌ | ❌ | ❌ |

**Scripts and `-c` load no user config.** They get the stdlib and the plugin
registry, nothing else. If a script needs a module, it must `use` it.

## `$env.config`

A record populated by Nushell, not inherited from the parent and not exported to
children.

**Assign to leaf keys.** Replacing a whole record silently resets every sibling
key to its internal default:

```nu
$env.config.show_banner = false        # right
$env.config = { show_banner: false }   # wrong — wipes everything else
$env.config.table.mode = 'psql'        # right
```

### Key groups

**History** — read once at startup; changing them from the REPL errors.
`history.file_format` (`plaintext` | `sqlite`), `max_size`, `sync_on_enter`,
`isolation`, `path`, `ignore_space_prefixed`. `sqlite` adds timestamps, cwd,
exit status, and session isolation. Switching format does not migrate old
entries.

**Editing** — `edit_mode` (`emacs`|`vi`), `buffer_editor` (string, list, or null
→ `$VISUAL`/`$EDITOR`), `cursor_shape.{emacs,vi_insert,vi_normal}`
(`block underscore line blink_* inherit`).

**Completions** — `completions.algorithm` (`prefix`|`substring`|`fuzzy`),
`.sort`, `.case_sensitive`, `.quick`, `.partial`, `.use_ls_colors`,
`.external.{enable,max_results,completer}`.

**Tables** — `table.mode` (see `table --list`), `.index_mode`, `.show_empty`,
`.padding.{left,right}`, `.trim`, `.header_on_separator`,
`.abbreviated_row_count`, `.missing_value_symbol`, `.batch_duration`,
`.stream_page_size`; plus `footer_mode`.

**Display** — `float_precision`, `filesize.{unit,show_unit,precision}`,
`datetime_format.{table,normal}`, `render_right_prompt_on_last_line`,
`ls.use_ls_colors`, `use_ansi_coloring` (`auto`|bool).

**Errors** — `error_style` (`fancy`|`plain`|`short`|`nested`), `error_lines`,
`display_errors.{exit_code,termination_signal}`.

**Terminal** — `shell_integration.{osc2,osc7,osc8,osc9_9,osc133,osc633,
reset_application_mode}`, `bracketed_paste`, `use_kitty_protocol`.

**Misc** — `show_banner` (`true`|`"full"`|`"short"`|`false`|`"none"`),
`rm.always_trash`, `recursion_limit`, `auto_cd_implicit`,
`clip.{resident_mode,default_raw}`.

**Other** — `hooks`, `keybindings`, `menus`, `abbreviations`, `color_config`,
`highlight_resolved_externals`, `explore`, `plugins`, `plugin_gc`,
`hinter.closure`.

## Environment variables

```nu
$env.FOO = "bar"
$env.FOO?                     # null if unset, instead of erroring
$env.FOO? | default "x"
"FOO" in $env
hide-env FOO                  # only if set in the current scope
load-env { A: 1, B: 2 }
with-env { FOO: bar } { ... } # temporary
FOO=bar cmd                   # single command
```

`$env` is **case-insensitive** on every OS (`$env.PATH` == `$env.Path`). Use
`$env | get --sensitive` if you need the real casing.

Changes are **scoped to the block**. A custom command must be `def --env` to
affect its caller. Same for `cd`, which is just `$env.PWD`.

### Nushell-specific variables

`$env.config` · `$env.PATH` (a list) · `$env.ENV_CONVERSIONS` ·
`$env.LAST_EXIT_CODE` · `$env.CMD_DURATION_MS` · `$env.NU_LOG_LEVEL` ·
`$env.NU_VERSION` · `$env.CURRENT_FILE` · `$env.FILE_PWD` ·
`$env.PROCESS_PATH` · `$env.SHLVL` · `$env.PROMPT_*` / `$env.TRANSIENT_PROMPT_*`

`$env.NU_LIB_DIRS` and `$env.NU_PLUGIN_DIRS` are **deprecated** in favour of the
`$NU_LIB_DIRS` / `$NU_PLUGIN_DIRS` constants. Both work; the const is searched
first and, unlike the env var, can be used by parse-time keywords.

### `ENV_CONVERSIONS`

Converts an env var between its string form (for externals) and a Nu value.
`PATH` is handled natively; everything else must be declared.

```nu
$env.ENV_CONVERSIONS = $env.ENV_CONVERSIONS | merge {
  XDG_DATA_DIRS: {
    from_string: {|s| $s | split row (char esep) }
    to_string:   {|v| $v | str join (char esep) }
  }
}
```

Conversion happens **after** `env.nu` and `config.nu` evaluate — inside those
files the values are still strings.

## The `$nu` constant

`default-config-dir` `config-path` `env-path` `loginshell-path` `plugin-path`
`history-path` `home-dir` `data-dir` `cache-dir` `temp-dir`
`vendor-autoload-dirs` `user-autoload-dirs` `pid` `os-info` `startup-time`
`is-interactive` `is-login` `history-enabled` `current-exe`

Constant, so usable with parse-time keywords:

```nu
source ($nu.default-config-dir | path join 'themes' 'x.nu')
```

## Hooks

REPL-only. They do not fire under `nu -c` or `nu script.nu`.

```nu
$env.config.hooks.pre_prompt ++= [{ ... }]
$env.config.hooks.pre_execution ++= [{ ... }]
$env.config.hooks.env_change.PWD ++= [{|before, after| ... }]
$env.config.hooks.display_output = "if (term size).columns >= 100 { table -e } else { table }"
$env.config.hooks.command_not_found = {|cmd| "message or null" }
```

Conditional form, needed because a plain `if` block scopes away its env changes:

```nu
$env.config.hooks.env_change.PWD ++= [{
  condition: {|before, after| $after | path join '.envrc' | path exists }
  code: "overlay use .envrc.nu"      # a string is evaluated as typed at the REPL
}]
```

A closure hook preserves `$env` changes but discards command/alias definitions.
Use the **string** form when the hook must define commands or aliases.

`display_output` wraps everything printed — a broken one hides all output. Reset
with `$env.config.hooks.display_output = null`.

## Integrations

Nushell cannot `eval` shell script, so `eval "$(tool init bash)"` has no
equivalent. Tools that support Nu emit a `.nu` file. The convention:

```nu
zoxide init nushell | save -f ($nu.data-dir | path join vendor autoload zoxide.nu)
atuin init nu       | save -f ($nu.data-dir | path join vendor autoload atuin.nu)
carapace _carapace nushell | save -f ($nu.data-dir | path join vendor autoload carapace.nu)
```

Files in `vendor/autoload` load automatically at startup, before your own
autoload dir. Regenerate them after upgrading the tool — init output changes
between versions.

Because generation is conditional on the tool being installed, this pattern is
also how you get "configure only if present" without runtime guards: no tool,
no file, nothing to load. Prune stale files when a tool is removed, or they will
fail at startup.

Two recurring hazards when composing integrations:

- **PATH filtering.** Some tools prepend a directory they create lazily
  (carapace's bridge dir). Since `vendor/autoload` runs *before* your own
  config, a `where {|p| $p | path exists }` filter on `$env.PATH` in your
  autoload will strip it on every launch. Use `uniq` alone.
- **`PATH` as a string.** Anything that round-trips the environment through an
  external (direnv) returns `PATH` as a string, breaking Nushell's list form.
  Re-convert with `do (env-conversions).path.from_string $env.PATH`
  (`use std/config *`).

Well-behaved integrations *append* to `hooks`, `keybindings` and
`completions.external` rather than assigning them, so they compose with `++=` in
later files. Verify with `$env.config.keybindings | get name` if a binding goes
missing.

Starship is the exception — it is invoked from `PROMPT_COMMAND` directly:

```nu
$env.STARSHIP_SHELL = "nu"
$env.PROMPT_COMMAND = {|| starship prompt --cmd-duration $env.CMD_DURATION_MS $'--status=($env.LAST_EXIT_CODE)' }
```

## Testing config safely

```nu
let tmp = (mktemp -d)
XDG_CONFIG_HOME=$tmp XDG_DATA_HOME=$tmp nu     # fresh, isolated
nu -n                                           # no config at all
nu --config /path/to/alt.nu
```
